# 記事の概要

　忙しい人向けのアブストラクトです。

　戦闘・工業・オープンワールドetc...と、とにかく要素がたくさんあるゲーム。  
　リリース時点で解放されている要素は、今まで遊んだ課金型基本無料ゲームの中で抜きん出ている。

　時間泥棒であるため、片手間にできるゲームを求めるなら回れ右。

- 好きな所

  - 集成工業システム
  - 戦闘

  - 演出 (キャラクターのアニメーション)
- 好ましくない所

  - ストーリー
  - 探索
  - UI
  - 音楽

　集成工業システムこと工業は、戦闘やオープンワールドの探索など他の要素に影響を与えており、広く楽しむには避けて通れない。  
　開発者はニッチなゲームジャンルと想定しているためか、工業のチュートリアルがかなり丁寧に作られている。  
　だが、丁寧すぎてテンポが悪いと感じた。

　戦闘は最大4人のキャラを編成して戦う。  
　連携技という、他のキャラクターの行動が前提となるアクションがあり、4人編成して戦うこと自体が前提。  
　キャラクターごとに発動の条件が異なり、その複雑さを楽しめるかどうかが戦闘の楽しさに直結すると感じた。

　ストーリーでのキャラクターの演出、表情や仕草はかなり力が入っている。  
　3Dモデルを活かしてギャグシーンやカッコいいシーンが挿入される。  
　またキャラクターのレベル上げや装備編成などの管理画面では『ゼンレスゾーンゼロ』方式の演出が採用されている。

　ただ、現在進められる範囲のストーリーそのものには面白さを感じられない。  
　主人公の記憶が失われているが、敵との戦い・復興が緊急の任務として優先され、掘り下げられる間があまりない。  
　謎ばかりを散りばめ、それを解き明かすフェーズがないためだろうか。

　オープンワールドで、移動をシームレスに行うことができる。  
　ジップラインも実装されているため、ある程度地形を無視した移動ルートを構築することもできる。  
　ただ探索そのものの楽しみは薄く、後半は作業か無視になりがち。日課や週課があるゲームとの相性も悪い。

　ガチャでの表記に不誠実さを感じた。  
　有償石と無償石が、単位の異なる別アイテムとして処理される。つまり、有償石1個 = 無償石75個 という計算を挟む必要がある。  
　更に課金ならば現金 → 有償石 → 無償石 と計算するため、煩わしい。

　音楽が期待していたものではなかった。  
　『アークナイツ』がレコード会社だと評されることもあるほどEPをたくさん出しており、全く知らない傍目から見て音楽に強い印象を感じていた。  
　しかし、本作のBGMでは印象に残る音楽が体験できなかったため、期待外れの不満となった。

　本作は非常に多くの要素を取り入れており、「何のゲーム？」と聞かれたときの回答が困る。  
　強いて言えば、"流行りを詰め込んでデフォルメした『DEATH STRANDING』"。  

　ここまで多くの要素を上手く融合させたのもなかなかに珍しいだろう。

---

PC版の推奨スペックは以下の通り。

- CPU : Intel Core i7-10700K 以上
- GPU : RTX 2060 以上
- メモリ : 16GB 以上
- ストレージ : 空き容量 50GB 以上のSSD

　CPUの要件は高めで、GPU要件は低めな印象。  
　GPUはFullHD液晶が前提かもしれないため、より高い解像度のモニターで遊ぶ場合は2060では足りなそう。

　メモリは長時間遊んでいると、アプリの使用量が最大6GBあたりまで膨らんだ。  
　進行や場面にもよると思うが、4.5GB ~ 5.5GBで安定していた印象。

# 集成工業システム

![](/images/end_field/indust_1.webp)

　その名の通り、工業のシステム。  
　……なのだが、現代の工業と比較して段違いに効率が良い。

　ゲーム的には、『Factorio』や『Minecraft』の工業Mod と説明すればわかる人がいるでしょうか。

　目的のアイテムを作る生産ラインを整え、そのアイテムの大量生産を目指す。

![](/images/end_field/indust_2.webp)

　更に土地が限られているため、生産ライン同士が被らないようにしたり、範囲内に収まるように設計したりとパズル的な楽しみ方があります。

　では具体的にどんなことに活きるのかというと、以下のことができます。

- 戦闘 : 防具素材の作成
- 戦闘 : 回復・補助アイテムの作成
- 探索 : 電気柵の解除で塞がれたところが行けるようになる
- 稼ぎ : アイテムと通貨の交換

---

　ジャンルとしてニッチな部類であることを開発側が認識しているためか、説明がめちゃくちゃ丁寧です。

　まずアイテムごとに説明欄が用意され、そこから

- どうやって入手するのか
- そのアイテムからどんなアイテムが作成できるのか
- 加工前提であれば、集成工業システムでどうすれば手に入るのか

　つまりはレシピがゲーム内で見られます。

![](/images/end_field/recipe_1.webp)

![](/images/end_field/recipe_2.webp)

# マップ&探索

　3Dアクションとは説明した気がしますが、マップはオープンワールドと定義しても良い気がします。  
　シームレスに移動ができます。

　マップのあちこちに敵やギミック、宝箱や素材が配置されており、条件が整っていればイベントが始まることもあります。

## ジップライン

　一番の特徴は、集成工業システムとの関連です。

　さきほど集成工業システムは土地が限られていると説明しましたが、例外があります。  
　生産ラインを作る以外のことは、集成工業システムのエリア外でも可能なんです！

　じゃあ何ができるかというと、こんなこと。

{{< youtube EjOQQjrFb40>}}

　マップ上の**任意の場所**にジップラインを立て、移動の利便性が上げられる！

　ただ、ジップラインには電力が必要。集成工業システムのエリアから電波塔経由で電力リレーをしていく手間がかかる。  
　つまりジップラインの設置と電力の供給のために、まずは歩き回る必要がある。  
　更に建設数にも限りがあるため、乱雑に建てるとすぐに許容量オーバーです。

　そのため、以下のように使い方を考えて設置します。

- マップの特定の場所にしかない素材を集める最短ルートの作成
- 崖と崖の間など移動できない場所の交通ルートの開拓
- 荷物の配達先への安全な交通ルートの開拓

{{< youtube nIRJ3dbNNA4>}}

　~~あれ？『DEATH STRANDING』で見たことがあるような……~~

　素材にはキャラクターのレベル上げのストッパー素材があり、一度回収すると数日かけて復活する。  
　つまり定期的な回収作業が求められるのだ。

　よって、毎回走って探し回るのと、ジップラインで直線上のルートで移動するとでは効率が段違い。

　ストーリーだけ楽しみたいなら必要ないでしょうが、戦闘コンテンツを楽しみたいなら楽するうえでは必須です。

---

　ジップラインではないですが、マップの一部には電力を供給しないと入れない場所があります。

　そこにはキャラクターの成長ストッパー素材や宝箱などがあるため、やはり戦闘をしっかりやるなら集成工業システムは必須……。

## 収集要素

### オーリレン

![](/images/end_field/orilen.webp)

　マップのあちこちに "オーリレン" と呼ばれる球が蔓延っており、触れることで回収できる。  
　わかりやすく言えば『ゼルダの伝説 ブレスオブザワイルド』のコログ。  
　遥かな宇宙を旅してやって来たらしい。

1. 止まっているもの
2. 動き回るもの
3. 止まっていると思いきや、近づくと逃げるように動くもの
4. 見えないもの

　の4種類がある。逃げるな！卑怯者！！  
　(画像中央上部あたりがその証。)

![](/images/end_field/orilen_yugami.webp)

　見えないものについては、 "スキャン" という機能を解放した後で見つけることができる。  
　ちょっと空間が歪んで見えるというヒントがあるため、その近くでスキャンすればOK。

![](/images/end_field/scan.webp)

　こんなスキャン色……見たことあるような？  
　~~やっぱり『DEATH STRANDING』じゃないか！~~

　一定以上集めるとガチャ石などの報酬が貰える。

　たまに、バトルで使用するスタミナの上限値が上昇することがある。  
　使い切ったことがないため、わざわざ狙ってあげるほどではないと思う。

　マップ探索の気まぐれ、ガチャ石が貰えたらいいなくらいで集めるのがちょうどいい。

### デルタロボット

![](/images/end_field/sos.webp)

　荷物を配達する自走型ロボット。  
　何らかの原因で故障してしまい、SOSを求めている。

　修理と称したパズルのミニゲームが始まる。

![](/images/end_field/puzzle.webp)

　黄色のSOSだと簡単で、赤色のSOSだと比較的難しい。  
　赤色で数分悩むことがたまにある。パズル好きにはおすすめ。

### 宝箱

![](/images/end_field/box.webp)

　赤や青など様々な色があり、色ごとにレアリティが割り振られている。  
　恐らく、灰 → 青 → 赤 → 金 とレアリティが上がり、報酬の内容も良くなる。

　基本的に探索で見つかるのは灰か青で、赤や金は戦闘の報酬に多い。

　わずかではあるがガチャ石が入手できる。

### 白△

![](/images/end_field/triangle.webp)

　宝箱と同様にアイテムが入手できる。  
　宝箱よりも数が多く、マップを探索すると各所に落ちている。

![](/images/end_field/triangle_item.webp)

　しかし、報酬がこんなものなので、あまり探索の旨味がない。  
　見た目も「白い三角……？」で宝箱よりもテンションが上がらない。

　序盤にはありがたいが、後半にはキャラクターの成長素材の要求数がかなり多い。  
　そのため、わざわざ回収するくらいなら別なことに時間を割いたほうがいい。  
　ただ、却って回収しないと景色を楽しみたい時に邪魔になる。

　恐らく、オープンワールドのマップがスカスカにならないように間を埋める用のアイテムなのでしょう。

　一応オーリレンや宝箱の近くに配置されることがあり、その時は "近くにもっと探索すべきものがあるよ" という道標として機能する。  
　オーリレンが宝箱がない時は、徒労感だけがあるので、それはご勘弁願います。

# 戦闘

{{< youtube sh6jn1QUpF0>}}

　最大4人までのメンバーで戦うことができる。

　操作は基本的にシンプル。攻撃ボタンを押し続けていれば、自然と通常攻撃のコンボが繰り出される。

　スタミナを消費して回避することができ、ギリギリで回避することで "ジャスト回避" となり、スキルを使うためのポイントが少し回復するオマケが付く。

　キャラクターには固有の3種類の技があり、その組み合わせが戦略性に奥行きを出している。

1. 戦技 - いわゆるスキル。SP……動画における画面中央下部の黄色バーを一つ消費して発動できる。
2. 連携技 - 条件を満たすと発動できるようになるスキル。一度発動するとしばらく使用できない。
3. 必殺技 - 強力な攻撃やバフが使えるスキル。カットインアニメーションが流れ、かっこいい。

　戦技と連携技は依存が深く、キャラ1の連携技の条件を満たすためにキャラ2の戦技が必要で、キャラ2の連携技の条件を満たすにはキャラ3の戦技が……
　ということがざら。

　このため、好きなキャラ4人で組もうとすると連携技の発動を諦めざるを得なくなる。  
　カードゲームのように、活かしたいメインのキャラ (テーマ) を一人選び、それにあった仲間を編成する……といった考え方をしたほうが良さそう。

　こういった組み合わせを考えるのが楽しい人なら楽しめると思います。

　初期メンバーの"管理人"と"ペリカ"はかなり連携技の条件が緩く、初心者でも扱いやすい。"チェン・センユー"も管理人の戦技からすぐに連携できる。

　ストーリーだけを追いたいなら、上記の初期メンバー3人を編成するとあれこれ考えずに楽しめるためおすすめです。

---

　集成工業システムは戦闘にも役立ち、防具を作成できる。

　装備できる防具は集成工業システムで生産する他なく、防具はステータスを大きく伸ばすことに寄与する。  
　防具といいつつも防御力以外のステータス、なんなら攻撃力も上げられるため、高レベルな戦闘コンテンツには必須。

# UI

## ガチャシステム

　いわゆるガチャ石500で1回、5000で10回です。

　大体ルールはこんな感じ。

![](/images/end_field/gacha_0.webp)

　ただ困ったことに最初はリリース記念で配布されたガチャチケットがありまして……  
　10枚以上所持していると、ガチャに必要な石の数が表示されないのです。

![](/images/end_field/gacha_1.webp)

　また、メインストーリーを進めたり、課金によって手に入るいわゆる有償石こと "展延源石" というアイテムがあります。  
　画像の通り、UI上では所持数に合わせて、ガチャ石何個相当か変換されて表示されます。

　しかし、肝心な、**展延源石1個が、ガチャ石何個分なのか**については教えてくれないのです。  
　電卓を使って計算すればすぐに分かりますが、**展延源石 1個 = ガチャ石 75個** です。

![](/images/end_field/gacha_2.webp)

　課金をするならば、更に現金〇〇円が展延源石の何個分相当……という計算が入り、煩わしい。

![](/images/end_field/kakin.webp)

　課金の元でゲームの継続的な開発が成り立っているのはわかりますが、ダークパターンのような手法には嫌気が差しますね。

## ローカライズ

　セリフの長さとイベントの移動が合わないことがある。

　また、移動によるイベントフラグの更新によってセリフが最後まで再生されず、途中で止まってしまうことがある。

　こればかりは翻訳の問題があるし、それを各言語で調整したら……作業量がとんでもないし、各ローカライズ班が介入できる部分でもないのだろう。

　基本的には翻訳がヘンという箇所は見受けられなかったため、品質はかなり高い。

# 音楽

期待していましたが、外れました。

　『アークナイツ』がレコード会社だと言われるくらいにEPをたくさん出しているです。  
　音楽の雰囲気をEPの感じで捉えていたため、すれ違いが発生した形。

　マップフィールドやメインストーリーのアニメーションシーンのBGMは、映画の劇伴音楽のようにメロディが薄く、ステレオタイプのゲーム音楽な雰囲気ではない。

　簡単に言えば、印象に残る音楽が何も無い。

　まぁ趣味趣向が合わないのでしょうね。  
　私はゲーム音楽を、そのゲームを思い出すための記憶装置だと捉えている節があります。  
　ゲームが遊べなくても音楽が聴ければ、特定の場面や体験の感傷に浸れますから。

# 総評

![](/images/end_field/endmini_2.webp)

　私は ストーリー・集成工業システム・音楽 に期待して始めました。  
　そして2つが期待外れであったため、思っていた楽しみ方ができませんでした。

　しかし、薦めるとすれば話は別です。  
　それは、コンテンツが多いために誰がどこを楽しめるかが全く異なると思ったから。

　同時に "片手間にできるゲーム" を探している人には薦められません。まぁ、これだけの要素があればわかるでしょう？

　私からは以下のように大まかにまとめられます。

- 好きな所

  - 集成工業システム
  - 戦闘

  - 演出 (キャラクターのアニメーション)
- 好ましくない所

  - ストーリー
  - 探索
  - UI
  - 音楽

　他にも紹介しきれないコンテンツや、気に入らないところはあるのですが、流石に長過ぎるため割愛。

　コンテンツ量は凄まじくとも、中毒性があるからついつい進めてしまうタイプのゲーム。  
　そのあたりの設計は上手いなと感じました。面白いかは別。

　色んな要素な流行りの要素を取り入れており、尖っているというよりは丸い。金平糖。  
　ただその要素が多すぎてデケェ！

　ただ、その分だけ学習量は比例する。  
　これは、"人間はどこまでの複雑化に耐えて楽しめるか" という一種の実験かもしれない。

　逆に言えば私にはそうとしか捉えられず、  
　「ここまで色んな体験をさせて、ユーザーに何をさせたいの？結局どんなゲームなの？」と単純化を求めてしまえば反りが合わなくなる。

　あえて単純化するなら、 "流行りを詰め込んでデフォルメした『DEATH STRANDING』"。~~単純か？~~

　ストーリーは単純なのに、ゲーム体験が複雑。そんな作品です。
